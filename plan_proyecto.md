# 📌 Proyecto: Portafolio Profesional de Desarrollador Web

## Descripción General
Sitio web profesional orientado a reclutadores técnicos, diseñado para comunicar el perfil del desarrollador, sus habilidades y proyectos en menos de 30 segundos.

**Stack Tecnológico:**  
React · JavaScript · HTML5 · CSS3 · Bootstrap

---

## 1. Arquitectura de Información

### Objetivo
Organizar el contenido para que la información clave sea fácil de encontrar, escanear y evaluar rápidamente.

### Mapa del Sitio

- Inicio  
  - Hero (propuesta de valor)  
  - CTA principal (Ver proyectos / Descargar CV)

- Sobre mí  
  - Perfil profesional  
  - Stack tecnológico

- Proyectos  
  - Proyecto 1  
  - Proyecto 2  
  - Proyecto N

- Contacto  
  - Formulario  
  - Enlaces profesionales

- Footer  
  - GitHub  
  - LinkedIn  
  - Email

### Jerarquía Visual de Secciones

1. Inicio / Hero  
2. Proyectos  
3. Sobre mí  
4. Contacto  

---

## 2. User Experience (UX)

### Objetivo UX
Permitir que un reclutador responda rápidamente:
- Quién es el desarrollador  
- Qué tecnologías domina  
- Qué proyectos ha realizado  

### Flujo de Usuario (Reclutador)

1. Accede al sitio y visualiza el rol + stack en el Hero  
2. Escanea las tarjetas de proyectos  
3. Lee el resumen profesional en “Sobre mí”  
4. Accede a GitHub, LinkedIn o Contacto  

**Tiempo estimado:** 20–30 segundos

### Principios UX Aplicados

- Escaneo visual (F-pattern)  
- Textos breves y directos  
- Llamados a la acción visibles  
- Navegación simple  
- Sin distracciones innecesarias

## 4. Copywriting Estratégico

### Sección “Sobre mí” (Ejemplo)

> Soy Desarrollador Web enfocado en crear interfaces claras, funcionales y orientadas a resultados. Trabajo principalmente con React y tecnologías frontend modernas, cuidando tanto la experiencia de usuario como la calidad del código.
>
> Me interesa construir soluciones reales, optimizar procesos y aprender continuamente nuevas herramientas que aporten valor a los proyectos.

### Títulos de Secciones

- Inicio: **Construyo experiencias web claras y funcionales**  
- Sobre mí: **Desarrollador Web orientado a resultados**  
- Proyectos: **Proyectos reales, soluciones reales**  
- Contacto: **Hablemos**

### Estructura para Descripción de Proyectos

**Nombre del proyecto**

**Problema**  
Descripción breve del problema o necesidad detectada.

**Solución**  
Cómo se resolvió el problema y qué tecnologías se utilizaron.

**Resultado**  
Impacto logrado, funcionalidad final o aprendizaje clave.

**Tecnologías:**  
React · JavaScript · Bootstrap · CSS · HTML

## 5. Especificaciones Técnicas

### Animaciones
- Framer Motion (recomendado para React)
- GSAP (animaciones más avanzadas)

> Usar animaciones sutiles y con propósito.

### Despliegue

| Plataforma | Uso recomendado |
|---|---|
| Vercel | React / SPA |
| Netlify | Alternativa estable |

### Optimización de Imágenes

- Uso de formato WebP  
- Compresión con TinyPNG o ImageOptim  
- Lazy loading  
- Peso recomendado por imagen: < 200 KB
